## 1. Guide prompt engineering 2025 — xix.ai (Academy, NOW)

**Points clés**
- Deux bénéfices documentés : (1) précision/pertinence accrues via prompts spécifiques ; (2) efficacité = moins de sorties inutiles → économie de temps et de **tokens/crédits API**.
- Base exploitable pour un module de formation interne (nouveaux arrivants + équipes non techniques).

**Actions**
- Créer une bibliothèque de prompts par métier (marketing, dev, finance).
- Référentiel de bonnes pratiques : contexte, rôle, format de sortie, exemples **few-shot**.
- Mesurer le gain de temps avant/après formation (KPI ROI transverse).

**Piège** : guide « débutant » = généraliste. À adapter aux outils internes réels + exemples propres ALNUA.

## 2. AI Trust Center — Eulidia / Dataiku / Groupe BPCE (App Dev, NOW)

**Points clés**
- Approche « AI Trust Center » : applications IA pertinentes, robustes, dignes de confiance.
- Thèmes : frameworks de tests, validation avant déploiement, gouvernance de la fiabilité.
- Outil socle cité : **Dataiku** (data science / MLOps).

**Piège** : source = compte-rendu d'événement, frameworks non détaillés. → Contacter Eulidia ou consulter la doc Dataiku pour l'implémentation.

## 3. IA « match-maker » éditeurs/marques — Journal du Net (Marketing, NOW)

**Points clés**
- IA pour identifier automatiquement le partenariat optimal éditeur/marque.
- Problème résolu : sourcing partenaire chronophage/incertain → recommandations data-driven.

**Actions**
- Outils de recommandation IA pour sélectionner supports/éditeurs en campagne.
- Optimiser collaborations influence / co-branding.
- Automatiser l'analyse d'affinité audience-marque.

**Pièges**
- Qualité recommandations = qualité des données d'entrée.
- Biais algorithmiques (toujours les mêmes profils).
- Garder un contrôle humain sur les choix stratégiques.
- Aucun outil ni chiffre de perf cité → évaluation marché requise.
